# 启动

## 日常开发（热更新，推荐）

```bash
cd /Users/nujabes/projects/step-coding && ./dev.sh
```

- 页面：<http://localhost:5173>（vite dev，改 `web/src/` 即时生效，**不用 build**）
- 接口：<http://localhost:5173/api>（vite 已把 `/api` 代理到 8790）
- 后端：`uvicorn --reload`，改 `backend/` 自动重启

## 单进程 8790（和线上一致，需要构建）

页面和 `/api` 都在 8790，用于验证「后端自己发前端」这套线上行为。前端改过要先打包：

```bash
cd /Users/nujabes/projects/step-coding && (cd web && pnpm build) && .venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8790
```

打开 <http://127.0.0.1:8790>。
