# 启动

页面和 `/api` 都在 8790，打开 <http://127.0.0.1:8790>。

## 平时启动（前端没改）

```bash
cd /Users/nujabes/projects/step-coding && .venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8790
```

## 重启（前端改过，先打包）

```bash
cd /Users/nujabes/projects/step-coding && (cd web && pnpm build) && .venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8790
```
